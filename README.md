# 고요사 가는 길 🏮

가상의 한국 산사를 여럿이 말없이 걷는 웹 3D 공간.
설치 없이 링크만 열면 들어올 수 있고, 모바일에서도 돌아갑니다.

- **산길 하나(약 535m, 느긋하게 걸으면 5분 안팎) + 절 마당**: 일주문 → 쉼터 돌탑 → 천왕문 → 대웅전·석탑·범종각
- **실시간 방문자 아바타** (최대 30명, 반투명한 모습으로 함께 걷기)
- **연등 달기 / 돌탑 쌓기**: 서버에 저장되어 다음 방문자에게도 남아 있음
- **앰비언트 사운드 + 낮/저녁/밤/새벽**: 산사의 하루는 20분. 모두에게 같은 시각이며 해질녘엔 범종, 새벽엔 목탁이 울림
- 3D 모델과 소리는 전부 코드로 생성(외부 에셋·라이선스 없음)

## 실행

```bash
npm install
npm run dev        # 개발: 서버(8787) + Vite(5173) → http://localhost:5173
```

```bash
npm run serve      # 빌드 후 단일 서버로 실행 → http://localhost:8787
```

개발 중 편의 주소 옵션: `?time=dawn|day|dusk|night` (시간 고정), `&debug` (콘솔용 `window.__dbg`).

## 구조
```
shared/path.js      산길·마당·돌탑 좌표 (서버/클라이언트 공용)
server/index.js     WebSocket + 정적 서빙 + data/state.json 저장
src/terrain.js      지형 높이/색 생성
src/world/          지형, 숲, 절 건물, 연등, 돌탑, 하늘, 플레이어
src/audio.js        WebAudio 합성 (바람·계곡·풀벌레·풍경·범종·목탁·발소리)
src/time.js         20분 주기 하루 + 키프레임
```

## 배포
WebSocket 서버가 필요해서 정적 호스팅(Vercel/Netlify)만으로는 안 됩니다.
Render, Fly.io, Railway 등 Node 서버를 띄울 수 있는 곳에 `npm run build && npm start`로 올리세요.
연등·돌탑은 `DATA_DIR`(기본 `./data`)에 저장되므로 **영구 디스크(볼륨)** 를 연결해야 재배포 후에도 남습니다.
환경변수: `PORT`, `DATA_DIR`.

## 알려진 한계 / 다음 단계
- 소원 글은 공개 텍스트입니다. 지금은 길이 제한과 태그 제거만 있으므로, 공개 운영 전 욕설 필터·신고 기능이 필요합니다.
- 접속자 제한은 서버 한 대 기준(30명)이고 IP별 제한은 없습니다.
- 계곡 소리는 있지만 시냇물 모델은 아직 없습니다.
- 나무·바위 충돌이 없어서 통과해서 걸을 수 있습니다.
- 연등이 96개를 넘으면 오래된 것부터 교체됩니다.
